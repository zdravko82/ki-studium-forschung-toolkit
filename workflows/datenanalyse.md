# Workflow: Datenanalyse mit Reproduzierbarkeit

Ziel: nachvollziehbare Schritte und robuste Interpretation.

## Schritt 1: Datenbeschreibung

Dokumentiere:

- Variablen
- Datentypen
- Stichprobe
- Missing Values
- Ausreißer
- Kodierungen

## Schritt 2: Analyseplan

KI kann passende Verfahren vorschlagen. Prüfe:

- Voraussetzungen
- Annahmen
- Alternativen
- Limitationen

## Schritt 3: Analyse durchführen

Nutze ein geeignetes Tool:

- R
- Python
- SPSS
- Stata
- Excel
- institutionelle Statistiksoftware

## Schritt 4: Robustheit prüfen

Beispiele:

- alternative Modellierung
- Sensitivitätsanalyse
- Stichprobencheck
- Plausibilitätsrechnung
- zweites Tool

## Schritt 5: Ergebnistext formulieren

Achte auf:

- keine unzulässige Kausalität
- klare Trennung von Ergebnis und Interpretation
- Limitationen
- alternative Erklärungen

## Schritt 6: Validierung dokumentieren

Halte fest:

- Datenbereinigung
- Code oder Rechenschritte
- Analyseentscheidungen
- KI-Unterstützung
- eigene Prüfungen
