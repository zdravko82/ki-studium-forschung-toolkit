# Mini-Checkliste: Tool-Risiken in 30 Sekunden

- [ ] Fakten: Kann ich jede zentrale Aussage belegen?
- [ ] Quellen: Gibt es DOI, Link, Journal oder Autor:in – und finde ich die Quelle wirklich?
- [ ] Kontext: Hat das Tool meinen Kontext verstanden?
- [ ] Eigenleistung: Ist erkennbar, was mein Beitrag ist?
- [ ] Datenschutz: Darf ich diese Daten in dieses Tool eingeben?
- [ ] Zweck: Nutze ich das passende Tool für die Aufgabe?

## Schnellwahl

- Denken, Struktur, Schreiben → Generalist
- Quellen, Paper, Evidenz → Recherche- oder Evidenztool
- Konkretes PDF oder Dokument → PDF-/Dokumenten-Assistent
- Tabellen, Folien, Office-Output → Produktivitäts-KI
