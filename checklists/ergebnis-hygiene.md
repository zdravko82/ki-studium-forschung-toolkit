# Checkliste: Ergebnis-Hygiene vor Abgabe

- [ ] Keine unzulässigen Kausalbehauptungen.
- [ ] Limitationen explizit genannt.
- [ ] Alternative Erklärungen erwähnt.
- [ ] Robustheitscheck vorhanden, falls empirisch gearbeitet wurde.
- [ ] Visualisierungen korrekt skaliert und beschriftet.
- [ ] Schlussfolgerung passt zur Forschungsfrage.
- [ ] Keine Überinterpretation kleiner oder unsicherer Befunde.
- [ ] Ergebnisse sprachlich von Interpretation getrennt.
