# Checkliste: KI-Transparenz

Dokumentiere mindestens:

- [ ] Wo wurde KI eingesetzt? Planung, Literatur, Schreiben, Analyse, Slides?
- [ ] Wofür wurde KI eingesetzt? Ideen, Stil, Struktur, Code, Visualisierung?
- [ ] Wie wurde geprüft? Quelle, Rechnen, Gegencheck, Betreuendenfeedback?
- [ ] Was wurde übernommen? Teilweise, gar nicht oder komplett – mit Begründung.
- [ ] Welche Tools wurden genutzt? Name, Version oder Datum.
- [ ] Welche Prompts waren zentral?
