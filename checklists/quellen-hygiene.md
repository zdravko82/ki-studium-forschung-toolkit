# Checkliste: Quellen-Hygiene vor Übernahme

- [ ] Quelle existiert nachweislich: DOI, Verlag, Journal, Bibliothekskatalog oder offizielle Website.
- [ ] Autor:in, Jahr und Titel stimmen.
- [ ] Wissenschaftliche Qualität plausibel: Peer Review, Fachverlag, institutionelle Quelle oder nachvollziehbare Methodik.
- [ ] Relevanz zur Forschungsfrage begründet.
- [ ] Primärtext mindestens quergelesen.
- [ ] Zentrale Aussagen im eigenen Text sind belegbar.
- [ ] Keine KI-generierte Literaturangabe ungeprüft übernommen.
- [ ] Zitationsstil konsistent.
