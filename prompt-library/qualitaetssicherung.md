# Prompts: Qualitätssicherung

## Wissenschaftstauglichkeit prüfen

```text
Prüfe den folgenden KI-Output darauf, ob er wissenschaftlich brauchbar ist. Bewerte:
1. inhaltliche Richtigkeit,
2. argumentative Tragfähigkeit,
3. wissenschaftliche Passung,
4. Belegbarkeit,
5. Risiken und Unsicherheiten.

Output:
[Text]
```

## Gegenposition erzwingen

```text
Nenne die stärksten Gegenargumente zu deiner eigenen Antwort. Welche Annahmen könnten falsch sein? Welche alternativen Erklärungen gibt es?
```

## Begriffe präzisieren


## Abgrenzung formulieren

```text
Formuliere explizit, was diese Antwort nicht behauptet. Achte besonders auf Kausalität, Vollständigkeit, Generalisierbarkeit und Datenbasis.
```
