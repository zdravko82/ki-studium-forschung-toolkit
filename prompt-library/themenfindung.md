# Prompts: Themenfindung & Eingrenzung

## Themenideen generieren

```text
Gib mir 15 Themenideen im Feld [Fachgebiet/Themenfeld], geordnet nach Aktualität und Machbarkeit. Berücksichtige, dass die Arbeit auf [Bachelor/Master/Seminar]-Niveau entstehen soll.
```

## Forschungsfragen formulieren

```text
Formuliere zu [Thema] 10 Forschungsfragen in 5 Formaten: Vergleich, Wirkung, Erklärung, Gestaltung und Bewertung. Gib pro Forschungsfrage eine kurze Begründung, warum sie wissenschaftlich interessant sein könnte.
```

## Forschungsfragen bewerten

```text
Bewerte diese Forschungsfragen nach Relevanz, Machbarkeit und wissenschaftlichem Beitrag auf einer Skala von 1 bis 5. Schlage anschließend präzisere Formulierungen vor.

Forschungsfragen:
[Liste einfügen]
```

## Abgrenzung schärfen

```text
Formuliere für das Thema [Thema] eine klare Abgrenzung: Was ist Teil der Arbeit, was ist ausdrücklich nicht Teil der Arbeit? Begründe die Abgrenzung kurz.
```

## Von Thema zu Problemstellung

```text
Ich interessiere mich für [Thema]. Liste 10 konkrete Problemstellungen in jeweils einem Satz auf. Ordne sie nach Relevanz für [Fach/Studiengang] und schlage je Problemstellung eine mögliche Variable, Beobachtung oder Analyseperspektive vor.
```

## Machbarkeit prüfen

```text
Für die Problemstellung [Problemstellung] nenne:
1. Welche Daten oder Quellen ich bräuchte,
2. ob das realistisch in [Zeitraum] ist,
3. welche Alternativen leichter machbar wären,
4. welche Risiken bei der Bearbeitung entstehen könnten.
```

## Theorieanschluss prüfen

```text
Welche drei theoretischen Perspektiven passen zu folgender Forschungsfrage?

[Forschungsfrage]

Nenne pro Perspektive zwei mögliche Argumente, ein Gegenargument und eine erste Suchrichtung für Literatur.
```
