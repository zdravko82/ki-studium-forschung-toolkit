# Prompts: Daten & Analyse

## Datenprofil erstellen

```text
Erstelle ein Datenprofil für den folgenden Datensatz bzw. die folgende Variablenliste. Prüfe Missing Values, Ausreißer, Variablentypen, mögliche Kodierungsprobleme und erste Analyseideen.

Datenbeschreibung:
[Daten/Variablen einfügen]
```

## Analyseverfahren empfehlen

```text
Meine Forschungsfrage lautet: [Forschungsfrage]
Meine Daten bestehen aus: [Datentypen, Stichprobe, Variablen]

Empfehle geeignete Analyseverfahren. Nenne pro Verfahren Voraussetzungen, Annahmen, Prüfschritte, Risiken und eine einfachere Alternative.
```

## Audit-Trail erzeugen

```text
Erstelle einen Audit-Trail für meine Analyse. Struktur:
1. Ziel der Analyse,
2. Datengrundlage,
3. Bereinigungsschritte,
4. Analyseverfahren,
5. Annahmen und Prüfungen,
6. Ergebnisinterpretation,
7. Limitationen,
8. Reproduzierbarkeit.

Meine Angaben:
[Angaben einfügen]
```

## Ergebnistext ohne Überbehauptung

```text
Formuliere aus diesen Ergebnissen einen wissenschaftlichen Ergebnistext ohne unzulässige Kausalbehauptungen. Nenne auch Limitationen und alternative Erklärungen.

Ergebnisse:
[Ergebnisse einfügen]
```

## Robustheitscheck planen

```text
Schlage kleine Robustheits- und Sensitivitätschecks für diese Analyse vor. Erkläre jeweils, was der Check prüft, wie er durchgeführt wird und welche Interpretation möglich ist.

Analyse:
[Analysebeschreibung]
```

## Visualisierung auswählen

```text
Welche Visualisierung passt zu diesen Daten und dieser Aussage? Gib 3 Optionen mit Vor- und Nachteilen sowie Hinweise zu Achsen, Beschriftung und möglichen Fehlinterpretationen.

Daten/Aussage:
[Beschreibung]
```
