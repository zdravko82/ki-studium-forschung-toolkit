# Toolübersicht für Studium & Forschung

| Kategorie | Beispiele | Typischer Nutzen | Risiko |
|---|---|---|---|
| Allgemeine Assistenten | ChatGPT, Gemini, Claude | Text, Ideen, Struktur, Code, Erklärungen | Faktenunsicherheit, Halluzinationen |
| Recherche / Wissenschaft | Elicit, Consensus, Perplexity AI | Literatursuche, Evidenzübersicht, Quellensynthese | unvollständige Coverage, falsche Zusammenfassung |
| PDF-/Dokumenten-Assistenten | SciSpace, ScholarAI, Chat mit PDF | Exzerpte, Begriffe, Paper-Verständnis | Kontextverlust, Fehlinterpretation |
| Schreiben / Überarbeiten | Notion AI, DeepL Write | Stiloptimierung, Kürzung, Übersetzung | Überglättung, Verlust eigener Stimme |
| Visualisierung / Präsentation | Canva Magic Design, Beautiful.AI, Gamma | Folien, Layout, Visual-Ideen | Design vor Inhalt, fehlende Quellen |
| Quellenmanagement | Zotero + Scite, Connected Papers | Literaturverwaltung, Zitationsnetzwerke | falsche Metadaten, unkritische Cluster |
